| Роль                         | Права роли                                                                                                                                                                                                                                                                | Группы пользователей                                                           |
|------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|
| **cluster-config-manager**   | * Полный CRUD на ресурсы приложений: Deployments, StatefulSets, DaemonSets, Jobs, CronJobs, Services, Ingresses, Pods, ConfigMaps, Secrets<br>* Просмотр Events и логов Pod<br>* Нет прав на управление `Node`, `Namespace`, `ClusterRole`, `ClusterRoleBinding`          | DevOps-инженеры платформенной команды; инженеры эксплуатации доменов           |
| **cluster-readonly**         | * Чтение (get/list/watch) всех основных ресурсов: Pods, Deployments, Services, Ingress, ConfigMaps, Events, логи Pod<br>* Просмотр Secret — только read, без модификации                                                                                                  | Архитекторы; аналитики; аудит; руководители направлений                        |
| **security-privileged-read** | * Полный read всех Secret и ConfigMap во всех неймспейсах<br> * Чтение RBAC-объектов: Roles, RoleBindings, ClusterRoles, ClusterRoleBindings<br>* Просмотр Cluster-wide ресурсов: Nodes, Namespaces, Pods, Events<br>* Нет прав на изменение                              | Специалист по информационной безопасности                                      |
| **namespace-admin**          | * Полный CRUD (get/list/watch/create/update/patch/delete) ресурсов в своём неймспейсе: Pods, Deployments, StatefulSets, Services, Ingress, ConfigMaps, Secrets<br>* Управление локальным RBAC (Role и RoleBinding внутри неймспейса)<br> * Нет прав на кластерные ресурсы | Команда разработки в конкретном домене/сервисе (например, команда tenant-core) |
| **namespace-viewer**         | * Чтение ресурсов внутри конкретного неймспейса: Pods, Deployments, Services, Ingress, ConfigMaps, Events<br> * Просмотр логов Pod<br>* Нет доступа к Secret                                                                                                              | Операционные команды; менеджеры продукта; support команды                      |
